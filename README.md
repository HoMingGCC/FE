# HoMing

결제 기록으로 단골 관계를 증명하고, 그 관계를 다시 결제로 되돌리는 서비스.

```bash
npm install
npm run dev
```

---

## 스택

| | |
|---|---|
| 빌드 | Vite 5 + React 18 + TypeScript |
| 상태 | Zustand |
| 스타일 | Tailwind CSS 3.4 |
| 라우팅 | React Router 6 |
| 폰트 | Pretendard (CDN) |

**브랜드 컬러는 `tailwind.config.js`에 토큰으로 있습니다.**

```
mint         #00CBA5   기본 액션 · 강조
mint.light   #EEFFFC   안내 카드 배경
mint.line    #B8ECE0   안내 카드 테두리
lime         #D7F3B7   주의 환기
```

색을 바꾸려면 config만 고치면 전부 따라옵니다. 컴포넌트에 하드코딩하지 마세요.

## 데이터 설계

**실제 가게 위에 합성 결제를 얹는 구조**입니다. 사업자등록번호가 조인 키예요.

```
① 가게 마스터 (12곳)     ← 실서비스에서는 당행 마스터 + 공공데이터
        ↓ regno로 조인
② 결제 원장 (합성)       ← 카드-008 / 선불-004 규격 형식
        ↓ 집계
③ 단골 판정 · 사장님 뷰 · 방문객 랭킹
```

**`payments.ts`는 결정적(deterministic)입니다.** 시드 고정이라 새로고침해도 같은 데이터가 나와요. 시연 중에 숫자가 바뀌면 안 되니까요.

### 목 데이터에 심어둔 케이스

| 가게 | 의도 |
|---|---|
| 봉덕 분식 27회 | 강한 단골 · 뱃지 시연 |
| 가나 미용실 19회 | 두 번째 핀 |
| 산격문구 **폐업** | 폐업 알림 · 대체 가게 플로우 |
| 큐 안경점 · 주연 이비인후과 | **비음식 업종** — "결제 기록은 삶의 기록" |
| 알파문구 3회 | 기준 미달 케이스 ("2번 남았어요") |
| 취소 건 2개 | 규칙 엔진이 제외하는 걸 보여주려고 |

### v1/v2/v3

`Payment.source`가 그 구분입니다.

```
localpay     지역화폐 — 동의 불필요 (당행 자사 원장)
im-card      당행 카드
other-card   타 카드사 마이데이터
```

iM샵 진입은 `localpay`만으로 시작해서 **동의 없이 지도가 이미 떠 있고**, 동의하면 나머지가 붙습니다. 지도 하단의 "지역화폐 8곳 · 카드 4곳"이 이걸 보여줘요.

## 단골 판정

**규칙 기반입니다.** 확률 모델을 안 쓴 이유는 화면에서 근거를 그대로 보여줘야 하기 때문이에요.

```
미용실 기준 10회 · 현재 19회 → 인증 완료
```

기준은 `lib/ontology.ts`에 **데이터로** 있습니다. 코드가 아니라서 기준이 바뀌어도 로직을 안 건드려요.

```ts
분식   10회
카페   15회
안경점  2회    ← 업종마다 다르다는 게 화면에 드러남
병원    4회    ← substitutable: false (대체 추천 안 함)
```

## 남은 작업

**우선순위 순**

1. **카카오맵 SDK 연동** — `MapHome.tsx`의 `<MapCanvas>`만 교체하면 됩니다. 지금은 좌표를 화면 비율로 정규화한 목업
2. 소식 피드 (`/feed`) — 폐업 알림 · 금융 제안 · 가게 소식
3. 마이페이지 (`/me`) — 연동 상태 · 금융 여정 · 철회
4. 사장님 축 — 대시보드 · 소식 보내기
5. 방문객 축 — QR 리스트 · 가게 상세 · 갈림길
6. 대체 가게 찾기 (v2)

### 카카오맵 붙일 때

`index.html`에 스크립트를 추가하고 `.env`에 키를 넣으세요.

```html
<script src="//dapi.kakao.com/v2/maps/sdk.js?appkey=%VITE_KAKAO_KEY%&autoload=false"></script>
```

`MapCanvas`의 인터페이스(`items`, `onPick`)는 그대로 두면 나머지 코드를 안 건드려도 됩니다.

## 시연 시나리오

```
1. 진입 → "iM뱅크에서 진입"
2. 동의 화면 — "이미 8곳이 준비됐어요" (지역화폐 = 동의 불필요)
3. 기간 선택 — 기본값 "고향 거주 기간"
4. 로딩 — 숫자가 올라감 ★ 5년치를 불러온다는 증거
5. 지도 — 핀에 방문 횟수
6. 핀 탭 → "27번 방문" 단골 인증
7. 폐업 핀 탭 → "산격문구가 문을 닫았어요"
```

**4번이 대체 불가능합니다.** 동의 누르자마자 지도가 뜨면 "진짜 불러온 건가?"가 남아요.
